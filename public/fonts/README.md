Place your licensed **Swis721 Cn BT** TrueType files in this folder using these exact names:

| File | Weight | Use |
|------|--------|-----|
| `Swis721CnBT-Roman.ttf` | 400 (regular) | Body text, regular headings |
| `Swis721CnBT-Bold.ttf` | 700 (bold) | Bold headings, emphasis |

## If your files have different names

Rename your `.ttf` files to match the table above. Common source names:

- `Swis721 Cn BT.ttf` → `Swis721CnBT-Roman.ttf`
- `Swis721 Cn BT Bold.ttf` → `Swis721CnBT-Bold.ttf`
- `Swiss721 Cn BT Roman.ttf` → `Swis721CnBT-Roman.ttf`
- `Swiss721 Cn BT Bold.ttf` → `Swis721CnBT-Bold.ttf`

These files are referenced from `src/app/swiss721.css` and served at `/fonts/…` on the live site.

**Important:** Only commit font files you are licensed to host on the website.
