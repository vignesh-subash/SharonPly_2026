# Use Case Section Icons

Upload the 6 homepage “Right Plywood for every purpose” **icon PNGs** here, then let the agent know to sync them.

## Expected files (`icons/` subfolder)

| File | Application |
|------|-------------|
| `icons/kitchen.png` | Kitchen Cabinets |
| `icons/wardrobe.png` | Wardrobes |
| `icons/vanity.png` | Bathroom Vanities |
| `icons/office.png` | Office Furniture |
| `icons/commercial.png` | Commercial Interiors |
| `icons/hospitality.png` | Hospitality |

Icons are served from `public/images/use-cases/icons/` on the live site. After uploading here, the agent copies them into that folder.

**Tip:** Dark or black line-art icons work best — they invert to white on card hover.
