# Product Image Uploads

Upload product photography here. Organise by category so replacements are straightforward.

## Structure

```
product-images/
  plywood/    ← Sharon Platinum, Gold, Prima Armor, Sovereign, Kumki
  door/       ← Sharon GOLD Door, Sovereign Door, BWP Doors
  veneer/     ← Exoti Natura, Exoti Aura, shade cards
  prelam/     ← Prelam product shots
  teak/       ← Teak product shots
  hero/       ← Page hero banners (plywood, door, veneer, etc.)
```
