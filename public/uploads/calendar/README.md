# Calendar Uploads

Upload calendar assets here, organised by year.

## Structure

```
calendar/
  2026/   ← page images (JPG/PNG) and optional PDF
  2025/
  2024/
  ...
  2005/
```

## What to upload

- **Page images** — one file per calendar page (cover + monthly spreads)
- **PDFs** — optional full calendar PDF for older years (2014–2022 style)

## Current site paths

The calendar page currently reads from `/images/Calendar/{year}/`. After you upload here, the agent will move or reference your files and update `src/app/calendar/page.tsx` as needed.

## Example filenames (2026)

- `Calendar sharonPly TTC 2026 - page - 1.jpg`
- `Calendar sharonPly TTC 2026 - page - 2.jpg`
- …through page 14

Use whatever filenames your files already have — no need to rename before uploading.
