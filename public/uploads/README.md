# Asset Uploads

Upload large calendar, catalogue, and product image files here. After you add files, let the agent know and the site references will be updated to use them.

## Folders

| Folder | Purpose |
|--------|---------|
| `calendar/` | Calendar page images and PDFs, organised by year |
| `catalogues/` | Catalogue PDFs and cover images |
| `product-images/` | Product cards, hero shots, and detail gallery images |

## Notes

- Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`, `.pdf`
- Keep original filenames if possible — the agent will map them to the correct pages
- For calendar years with multiple pages, upload all pages into the matching year folder
- For catalogues, place PDFs in `catalogues/pdfs/` and cover images in `catalogues/covers/`
